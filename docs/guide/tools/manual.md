# Csound Manual

Look up an opcode without leaving your project.

## Find an article

Open Csound Manual from the tool controls. Use the search icon to reveal the search field. The header also has previous and next article controls and back and forward history.

With an opcode selected in the editor, use the documentation shortcut or the synopsis panel's **Open in manual** link. The IDE reuses a manual that is already open.

## Use examples

Hover a code example to reveal its copy icon. Copy the example into your own source and check its options before running it. Where the article offers an example file, you can open it for study.

A temporary example tab is not a saved project file. Add or save the code in your own project when you want to keep it.

## Make room

Place the manual beside the editor or in the lower section, then drag the divider to resize it. The manual scrolls within its panel.

This guide explains the Web-IDE. The manual explains the Csound language and opcodes in detail.
