# Mixer

Combine audio files on a timeline and export one mix.

## Add tracks

Choose project files or open audio from your computer. Each track shows its waveform and position. Add the sounds you want to combine, then set their start times on the timeline or with the start control.

## Balance the mix

Set each track's gain and channel routing. Mute leaves a track out of the mix. Solo lets you hear selected tracks together. Output gain adjusts the combined result.

The preview rebuilds after you pause changing a control. Listen from the shared player and watch the loading state while a new mix is being prepared.

## Undo a setting

The changes list records track and output adjustments. Remove an adjustment to restore its default. Reset controls let you return to a starting mix without repeatedly adding processing to an old result.

## Export

Download the mixed audio or add it to the local file list. Upload that result if you want to save it in your project. The mixer combines files offline; it does not control the live instruments in a running Csound performance.
