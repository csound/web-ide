# Choose a tool

Open tools from the editor controls. On smaller screens, look in More.

## Listen and inspect

| Task                            | Tool                                      |
| ------------------------------- | ----------------------------------------- |
| Read compiler output            | [Console](console.md)                     |
| Look up opcodes and examples    | [Csound Manual](manual.md)                |
| Play notes without a controller | [Virtual MIDI Keyboard](midi-keyboard.md) |
| Watch the live spectrum         | [Spectral Analyzer](spectral-analyzer.md) |
| Plot a function table           | [FTGEN plotting](../editor/ftgen.md)      |

## Keep the result

Conversion tools load their engines when you use them. The first run may take longer. A loading indicator belongs to the tool doing the work.

**Download** keeps a file on your computer. **Add to project** puts a generated file in the local file list. Use the Upload icon there to keep it in cloud storage if you own the project. See [Files and saving](../projects/filesystem.md).
